# Architecture

## Monorepo Structure

```
design-system/
├── apps/
│   ├── docs/          # Documentation site
│   └── storybook/     # Component documentation
├── packages/          # Component packages (@uiid/*)
│   ├── buttons/, cards/, forms/, layout/, typography/, ...
│   └── tokens/        # Design tokens (JSON → CSS, generated by build-tokens.js)
├── scripts/           # Build helpers and CI checks
└── .claude/           # Agent rules (rules/) and skills (skills/uiid/)
```

## Root Config Files

| File                    | Purpose                                                                                                    |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| `vite.config.ts`        | Shared Vite build config factory                                                                           |
| `vitest.config.ts`      | Test configuration for all packages                                                                        |
| `vitest.setup.ts`       | Test setup (jest-dom matchers)                                                                             |
| `vitest.globalSetup.ts` | Generates token CSS and per-icon modules, so tests need no build; Storybook's `main.ts` does the same      |
| `tsconfig.json`         | Base TypeScript config                                                                                     |
| `tsconfig.package.json` | Package build config every `packages/*/tsconfig.json` extends: declaration-only emit to `dist`, no tests   |
| `tsconfig.check.json`   | Build-free `pnpm typecheck` of packages and Storybook; `apps/docs/tsconfig.check.json` covers the docs app |
| `turbo.json`            | Turbo task orchestration                                                                                   |
| `.size-limit.js`        | Size entries, generated from `packages/*`                                                                  |
| `.oxlintrc.json`        | oxlint configuration (whole repo)                                                                          |
| `.oxfmtrc.json`         | oxfmt formatter configuration                                                                              |
| `lefthook.yml`          | Git hooks (pre-commit format+lint, commit-msg)                                                             |
| `.nvmrc`                | The one declared Node major, read by nvm/fnm and every `actions/setup-node` step; Vercel does not read it  |
